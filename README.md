# Reality Bending — Forge 1.20.1

A Minecraft Java Edition 1.20.1 mod containing ten reality-bending artifacts. Java 17 and Forge 47.2.0.

## Items
- **Rift Pearl** — teleport toward the surface you look at, or blink forward into open space.
- **Gravity Core** — pull nearby entities toward you.
- **Chrono Shard** — slow and weaken nearby living entities.
- **Phase Crystal** — temporary invisibility, speed, and jump boost.
- **Return Anchor** — save your position, then return to it in the same dimension.
- **Blink Charm** — launch yourself in the direction you look.
- **Null Orb** — push nearby living entities away.
- **Mirror Token** — temporary Resistance and Absorption.
- **Time Bottle** — heavily slow nearby living entities.
- **Echo Step** — speed, jump boost, and slow falling.

Each artifact has a cooldown, a custom texture, and a shapeless crafting recipe.

## Cloud build from iPhone
1. Open the Actions tab and enable Actions if prompted.
2. Choose **Build Reality Bending → Run workflow**, or push a commit to main.
3. Open the successful run and download the **realitybending-forge-1.20.1** artifact.
4. Extract the artifact ZIP and put **realitybending-1.0.0.jar** in the mods folder for Minecraft Java 1.20.1 with Forge installed.

No local computer or API key is needed. The first build may take several minutes while Forge dependencies download. If the build fails, share the Actions log so the failing step can be corrected.
