# Reality Bending 2.0 — Forge 1.20.1

Minecraft Java Edition 1.20.1 mod with ten reality-bending items. Requires Java 17 and Forge 47.2.0.

## Items

- **Telekinesis Unlock** — use once to unlock telekinesis for your player. In Survival the item is consumed; in Creative it remains. You do not need to hold it afterward. Press **G** to toggle the power. When enabled, aim at a living entity within 14 blocks to pull it toward a point in front of you.
- **Manifesto Parody Relic** — dark satire of an infamous online manifesto and “supreme gentleman” persona; framed as mockery rather than praise. Grants invisibility, speed, and slow falling.
- **Reality Check** — outlines nearby living entities and slows them briefly.
- **Plot Armor** — grants resistance, absorption, and regeneration.
- **Lag Spike** — heavily slows nearby living entities and their mining.
- **Pocket Dimension** — blinks you to a nearby safe landing spot in the direction you look.
- **Admin Wand** — briefly levitates nearby living entities.
- **Chaos Dice** — rolls a random beneficial effect for you.
- **Meme Beacon** — gives you speed and outlines nearby living entities.
- **Gravity Boots** — grants jump boost, slow falling, and a speed boost.

All ten items are registered and explicitly added to the Creative inventory's Ingredients tab. Each has a crafting recipe and item model.

## Build

1. Open [GitHub Actions](https://github.com/iamlordst-jpg/ai-mod-mc/actions).
2. Wait for the latest **Build Reality Bending** run to succeed.
3. Download the **realitybending-forge-1.20.1** artifact and extract the ZIP.
4. Put the JAR in the mods folder for Minecraft Java 1.20.1 with Forge installed.
